# KVB_LCD Graphics Library
## 🌐 Как подключить библиотеку (.lib) к проекту в Keil MDK 5
Графические библиотеки (**.lib**) для **LCD** панелей лежат в папке проекта **KVB_LCD**, там же лежит **GUI** и файлы презентации (**.c** и **.h**).
## 📂 Обзор структуры файлов
* **KVB_LCD.h** – GUI графический интерфейс пользователя.
* **KVB_TEST.h** – Заголовочный файл с двумя функциями презентации в зависимости от разрешения.
* **KVB_TEST.c** – Исполняемый файл с двумя функциями презентации в зависимости от разрешения.
* **KVB_TEXT.h** – Заголовочный файл текстовых переменных презентации.
* **KVB_TEXT.c** – Исполняемый файл текстовых переменных презентации.
* **LCD_16bit_Open407_F407VGT6_9325.lib** – Файл библиотеки **LCD** панели **ILI9325** с разрешением **320 х 240**.
* **LCD_16bit_Open407_F407VGT6_9341.lib** – Файл библиотеки **LCD** панели **ILI9341** с разрешением **320 х 240**.
* **LCD_16bit_Open407_F407VGT6_9481.lib** – Файл библиотеки **LCD** панели **ILI9481** с разрешением **480 х 320**.
* **LCD_16bit_Open407_F407VGT6_9486.lib** – Файл библиотеки **LCD** панели **ILI9486** с разрешением **480 х 320**.
* **LCD_16bit_Open407_F407VGT6_8009A.lib** – Файл библиотеки **LCD** панели **OTM8009A** с разрешением **800 х 480**.
## ⚙️ Настройте Линкер (Линковщик) и GUI:
1. В левой панели **Keil** (**Project Tree**) откройте папку **KVB_LCD**, если в ней уже подключена библиотека (**.lib**) другой **LCD** панели, то удалите ее нажатием правой кнопки мыши на файл (**.lib**) и выбрав в выпадающим списке **Remove File** ‘**xxxx.lib**’, должна быть подключена только одна графическая библиотека в проекте.
2. В левой панели **Keil** (**Project Tree**) нажмите правой кнопкой мыши на папку **KVB_LCD**, выберите **Add Existing Files to Group...**
3. В окне выбора файла внизу в выпадающем списке "**Files of type**" переключите на **Library file (*.lib; *.a)**.
4. Выберите ваш файл **LCD_16bit_Open407_F407VGT6.lib** и нажмите **Add**.
5. Теперь **Keil** знает, что этот бинарный файл нужно линковать (склеивать) с основным кодом.
6. В файле графического интерфейса пользователя **KVB_LCD.h**, строка **120**, рас комментируйте только строку вашей **LCD** панели, там находится усредненная установка задержек шины **FSMC** панели, она зависит от конкретной реализации панели, длины проводников и шлейфа.
7. Теперь в файле **main.c** вашего конечного проекта вы должны снять комментарии с одной из двух функций презентации в зависимости от разрешения **LCD** панели (**lcd_Test480x320Landscape()** или **lcd_Test320x240Landscape()**).

При сборке **Keil MDK 5** автоматически заберет скомпилированный код из файла библиотеки **LCD_16bit_Open407_F407VGT6_9486.lib**.

⚠️ **ВАЖНО!!!** Из за большой скорости передачи данных в **GRAM**, если установлен шлейф, надо **ОБЯЗАТЕЛЬНО** поставить гасящую отражения емкость **22 пф** на конце шлейфа, как можно ближе к разъему панели по сигналу записи **WE**.
